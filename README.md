# EchoType — Type to Make Music

Cyberpunk Lo-Fi musical typing game. Every correct keystroke plays an A-minor synth note with neon ripple feedback. Incorrect keys break combo with a low thud.

Built with Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS v4 + Framer Motion + Raw Web Audio + Raw Canvas. No backend — LocalStorage only.

## Modes
- Freeform Jam
- Quote Challenge
- Code Snippet

## Tracks
- Lo-Fi Chill
- Synthwave Groove
- Ambient Drone

## Quickstart
```bash
npm install
npm run dev
```

Open http://localhost:3000
